# To Be Read (TBR) List Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the Dashboard's disabled "To Be Read" placeholder into a working feature: add a book you want (title and/or author, optional city/state), see it listed, delete it, and get a link to a matching active listing if one exists.

**Architecture:** A new `tbr_entries` table stores each request. Two FormData-shaped server actions (`addTbrEntry`, `removeTbrEntry`) in a new `lib/actions/tbrEntries.ts` back a plain `<form action>` in the Dashboard — no client-side JS needed, matching the `updateListingStatus`/`removeSavedListing` convention (unlike `saveListing`/`unsaveListing`, there's no optimistic-UI requirement here). `app/profile/page.tsx` fetches the user's TBR entries and, for each one, resolves at most one matching active `listings` row (title/author `ilike`, city `ilike`, and state via a `profiles!inner(state)` embedded join since `state` lives on `profiles` not `listings`) before handing everything to `DashboardClient`.

**Tech Stack:** Next.js 14 App Router, React 18, Supabase (`@supabase/ssr`).

## Global Constraints

- `tbr_entries` schema, exactly as specified in Task 1 — do not alter column names or the `tbr_title_or_author` check constraint.
- At least one of `title`/`author` must be non-blank to add an entry — enforced both server-side (friendly redirect+error) and at the DB level (check constraint as backstop).
- No demo-mode persistence for TBR entries (same rule as `saved_listings` — the demo branch in `app/profile/page.tsx` leaves `tbrEntries` as `[]`).
- No real-time/push notification when a new matching listing is posted — matches are only resolved when the Dashboard page loads. No editing of an existing entry (delete-and-re-add only).
- Both server actions are FormData-shaped and invoked via `<form action>`, not called directly from client code.
- At the end, the exact SQL from Task 1 must be handed to the user to run in the Supabase SQL editor.

create table if not exists tbr_entries (
  id uuid default gen_random_uuid() primary key,
  user_id uuid references profiles(id) on delete cascade not null,
  title text not null default '',
  author text not null default '',
  city text not null default '',
  state text not null default '',
  created_at timestamptz default now(),
  constraint tbr_title_or_author check (title <> '' or author <> '')
);

alter table tbr_entries enable row level security;

create policy "Users can view own tbr entries" on tbr_entries
  for select to authenticated using (auth.uid() = user_id);

  for insert to authenticated with check (auth.uid() = user_id);

create policy "Users can delete own tbr entries" on tbr_entries
  for delete to authenticated using (auth.uid() = user_id);

- [ ] **Step 1: Write the file**

Create `lib/actions/tbrEntries.ts`:

```ts
'use server'

import { createClient } from '@/lib/supabase/server'
import { redirect } from 'next/navigation'

export async function addTbrEntry(formData: FormData): Promise<void> {
  const title = ((formData.get('title') as string) || '').trim()
  const author = ((formData.get('author') as string) || '').trim()
  const city = ((formData.get('city') as string) || '').trim()
  const state = ((formData.get('state') as string) || '').trim()

  if (!title && !author) {
    redirect('/profile?tbr_error=' + encodeURIComponent('Enter a title or an author.'))
  }

  const supabase = createClient()
  const { data: { user } } = await supabase.auth.getUser()
  if (!user) redirect('/auth/signin?redirect=/profile')

  await supabase.from('tbr_entries').insert({
    user_id: user.id,
    title,
    author,
    city,
    state,
  })

  redirect('/profile')
}

export async function removeTbrEntry(formData: FormData): Promise<void> {
  const supabase = createClient()
  const { data: { user } } = await supabase.auth.getUser()
  if (!user) redirect('/auth/signin?redirect=/profile')

  const id = formData.get('id') as string

  await supabase
    .from('tbr_entries')
    .delete()
    .eq('id', id)
    .eq('user_id', user.id)

  redirect('/profile')
}
```
